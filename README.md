
# Citinet — Info Site

Public landing and information site for the Citinet project. Built with Astro 5 + React 18 + Tailwind CSS 4.

Auto-deploys to Vercel on `git push`.

## Development

```bash
npm i
npm run dev
```

## Related Citinet Repositories

- [citinet](https://github.com/fergtech/citinet): Web portal and hub stack (API, Docker Compose, setup-script generator, admin sidecar)
- [citinet-registry](https://github.com/fergtech/citinet-registry): Public hub registry (GitHub-backed JSON)
- [citinet-docs](https://github.com/fergtech/citinet-docs): Admin, user, and architecture documentation
